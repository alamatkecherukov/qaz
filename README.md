# Telegram-бот для обратной связи "Ученик-Учитель"

## Описание

Этот Telegram-бот позволяет ученикам отправлять вопросы учителям в виде текста, аудио, видео, фото и любых других файлов. 
Когда ученик задает вопрос, он приходит всем учителям. Первый учитель, который нажимает кнопку "Принять вопрос", 
начинает диалог с учеником. Все последующие сообщения от этого ученика будут направляться только этому учителю, 
пока он не нажмет кнопку "Завершить диалог".

## Функциональность

- Поддержка текстовых сообщений, фото, видео, аудио, документов, голосовых сообщений, стикеров и GIF
- Распределение вопросов между несколькими учителями
- Система сессий: один учитель может вести диалог с одним учеником до завершения сессии
- Уведомления учителей о новых вопросах
- Защита от неактивности для работы на Render (24/7)

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <ваш_репозиторий>
cd "тг бот"
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` в корне проекта и укажите следующие параметры:

```
# Токен вашего Telegram-бота (получить можно у @BotFather)
BOT_TOKEN=ваш_токен_бота_здесь

# ID учителей, разделенные запятой (например: 123456789,987654321)
TEACHER_IDS=123456789,987654321

# Путь к базе данных
DATABASE_PATH=database/bot_database.db
```

Замените `ваш_токен_бота_здесь` на реальный токен, полученный от @BotFather в Telegram.

Замените `123456789,987654321` на реальные ID учителей, которые будут обслуживать бота. Можно указать одного или нескольких учителей.

### 4. Запуск бота

```bash
python main.py
```

## Использование

### Для учеников:
1. Найдите бота в Telegram по имени, которое вы указали при создании
2. Отправьте команду `/start`
3. Отправьте свой вопрос в виде текста, фото, видео, аудио или любого другого формата

### Для учителей:
1. Когда ученик задает вопрос, все учителя получают уведомление с кнопкой "Принять вопрос"
2. Нажмите кнопку "Принять вопрос", чтобы начать диалог с учеником
3. После принятия вопроса все последующие сообщения от этого ученика будут приходить только вам
4. Чтобы завершить диалог, нажмите кнопку "Завершить диалог"
5. После завершения диалога, новые вопросы от этого ученика снова будут доступны всем учителям

## Развертывание на Render

1. Создайте аккаунт на [Render](https://render.com/)
2. Создайте новое веб-приложение
3. Укажите репозиторий с исходным кодом
4. В качестве команды сборки используйте:
   ```bash
   pip install -r requirements.txt
   ```
5. В качестве команды запуска используйте:
   ```bash
   python main.py
   ```
6. В переменных среды укажите те же параметры, что и в файле `.env`:
   - `BOT_TOKEN`
   - `TEACHER_IDS`
   - `DATABASE_PATH`

## Защита от неактивности

Для обеспечения работы бота 24/7 на Render реализована система, которая каждые 10 минут отправляет запрос к API Telegram, 
чтобы сервер не переходил в спящий режим. Это достигается с помощью модуля `utils/keep_alive.py`.

## Возможные проблемы и решения

### Бот не отвечает
- Проверьте, правильно ли указан токен бота в файле `.env`
- Убедитесь, что бот не заблокирован пользователем
- Проверьте подключение к интернету

### Учителя не получают уведомления
- Проверьте, правильно ли указаны ID учителей в файле `.env`
- Убедитесь, что учителя начали диалог с ботом (отправили ему любое сообщение)
